# Edupro School Fees - Frappe App

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

School Fees & Financial Statements System for Zimbabwean Schools.

## Features

- **School Setup**: Complete school information management
- **Banking Configuration**: Multi-currency (ZiG, FCA) banking setup with fee streams
- **Fund Configuration**: Tuition/Government and SDC/SDA Project accounts
- **Branding**: Customizable colors, receipt and statement templates
- **Role-based Permissions**: System Admin, School Head, Bursar

## Installation

1. Install Frappe Framework
2. Get the app:
   ```bash
   bench get-app edupro_school_fees
   ```
3. Install on site:
   ```bash
   bench install-app edupro_school_fees
   ```

## Usage

After installation, navigate to:
- School Setup: Create your school configuration
- Banking Configuration: Set up bank accounts for different fee streams
- Academic Year: Manage academic years
