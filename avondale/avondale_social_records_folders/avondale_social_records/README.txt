Avondale Primary School - Student Social Records Scanning Folders
====================================================================

Structure:
  <Level>/Class <A-E>/

Levels covered: ECD A, ECD B, Grade 1 - Grade 7 (9 levels total)
Classes per level: A, B, C, D, E (5 classes)
Total class folders: 45

Suggested file naming when scanning:
  <Surname>_<FirstName>_SocialRecord.pdf
  e.g. Moyo_Tapiwa_SocialRecord.pdf

Place each scanned social record inside the correct
"<Level>/Class <X>/" folder for the student's class.

Feel free to rename "ECD A" / "ECD B" to match the school's actual
naming (e.g. "ECD A" vs "Baby Class"/"Nursery" etc.) if different.
